API Reference

Classes

Name Description
Item The Item struct, contains a value of any kind, and a function to free the value and print the value.
List The List struct, contains a header for size, capacity, and resizing multiple and then a List of Items.
HashMap The HashMap struct, contains a header for size, capacity, and resizing multiple. Has a list of entries and a pointer to a hashing function.
HashMapItem The HashMapItem struct. Contains the key, the value, and a next field for collisions.

Typedefs

ItemFreeFunction

using ItemFreeFunction = void

A function that will be a part of the Item struct, it determines how the Item will be freed.

ItemPrintFunction

using ItemPrintFunction = void

A function that will be a part of the Item struct, it determines how the Item will be printed, mainly for debugging.

HashFunction

using HashFunction = u_int32_t

A Function that takes key and a capacity and hashes the key to return an index.

HashMap

#include <standardloop/collections.h>

struct HashMap

The HashMap struct, contains a header for size, capacity, and resizing multiple. Has a list of entries and a pointer to a hashing function.

Public Attributes

Return Name Description
u_int32_t size The current size (number of entries) of the HashMap.
u_int32_t capacity How large the HashMap can get before it needs to be resized.
u_int8_t resize_multiple If the HashMap needs to be resized, what should the resizing multiple be
u_int32_t collision_count How many collisions have occured.
HashMapItem ** entries The List entries in the HashMap.
HashFunction * hashFunction The function this HashMap uses to Hash strings.
bool force_lowercase Should only lowercase be considered, for example "THIS" and "this" are both hashed to the same value.
